# Amplats Piping Spec Selector

Streamlit app to filter Amplats piping specifications by commodity, material, and design code.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Features

- Filter by Commodity / Service
- Filter by General Material
- Filter by Design Code
- View matching specs
- Drill into a selected spec for header details and related valves

Place the Excel master data files in the same directory as `app.py`.
